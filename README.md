# インボイス経過措置 影響シミュレーター

1年分の仕訳CSVから課税区分52・62・72を抽出し、免税事業者等からの課税仕入れに係る経過措置率の変更が、仕入控除税額へ与える影響を概算するブラウザツールです。

## 公開URL

- GitHub Pages: https://takatrp.github.io/invoice-transition-impact/
- Sites: https://invoice-transition-impact.takatrp0222.chatgpt.site/

## 主な機能

- UTF-8 / Shift_JISのCSVをブラウザ内だけで解析
- TKC仕訳帳49列形式（「月日」「借方／貸方課税区分」「借方／貸方取引金額」「借方／貸方消費税等」「取引先名」「元帳摘要」）を自動判定
- 単一列形式と借方・貸方形式の見出しを自動判定
- 読み取る課税区分・金額・税率・税額・仕入先・取引日列を画面で修正
- 80%・70%・50%・30%・0%の任意のBefore / After比較
- 元CSVから観測した日付範囲を初期表示し、開始日・終了日の確認後に影響額を365日換算
- 年換算時は、確認した集計期間外や日付不明の対象明細を分子から除外して件数を表示
- 全額控除、個別対応方式、一括比例配分方式、簡易課税等の切替
- Before / After / 登録事業者100%の仕入控除税額と、全仕入先の差額を表示
- CSVテキスト上の開始物理行とデータ行、日付、区分、金額、税率、100%税額相当、CSV税額、除外理由を検算明細で表示
- 税率を既定値で補った場合や、年換算で日付不明明細を除いた場合は主結果にも「参考値」と表示
- 税抜入力時も明細ごとの税率で税込支払総額へ換算し、期間実績と年換算見込みの1仕入先1億円超を警告
- 借方・貸方の片側で課税区分列または金額列が欠けた場合は、読み取り設定で明示して試算を停止

## データ取扱い

- CSVはブラウザ内だけで処理し、サーバーへ送信・永続保存しません。
- 公開URLで実データを扱う際は、画面共有やスクリーンショットに仕入先名・金額が映らないよう注意してください。

## 計算対象

- 課税区分52：免税事業者等からの課税仕入れ（課税売上げ対応）
- 課税区分62：免税事業者等からの課税仕入れ（非課税売上げ対応）
- 課税区分72：免税事業者等からの課税仕入れ（共通対応）

経過措置率は令和8年度税制改正後の 80% → 70% → 50% → 30% → 0% を採用しています。

## 試算式

以下の試算式は、税込金額と消費税・地方消費税の合計ベースです。

```text
仕入税額相当額（標準税率） = 税込額 × 10 / 110
仕入税額相当額（軽減税率） = 税込額 × 8 / 108
制度変更の影響 = 配分後の仕入税額相当額 ×（Before率 - After率）
登録事業者との差 = 配分後の仕入税額相当額 ×（100% - After率）
年間換算の影響 = 確認した集計期間内の影響 × 365日 ÷ 確認した日数（両端を含む）
```

CSVの消費税等列は経過措置適用後の値を含むことがあるため、計算には使用しません。取引金額と税率から100%の仕入税額相当額を算出し、CSV税額は検算明細に表示します。

「税抜」を選ぶ場合は、控除対象外消費税等を含まない純粋な本体金額を入力値とします。可能な場合は税込支払総額を使用してください。1仕入先ごとの1億円超警告は、税抜入力でも各明細の税率を用いて税込支払総額へ換算し、期間実績と年換算見込みを判定します（上限額自体の精密計算は行いません）。

実際の納付税額確定には、売上税額、端数処理、課税売上割合、保存要件、1仕入先ごとの上限、棚卸資産調整などの確認が必要です。
