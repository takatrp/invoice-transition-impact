# インボイス経過措置 影響シミュレーター

1年分の仕訳CSVから課税区分52・62・72を抽出し、免税事業者等からの課税仕入れに係る経過措置率の変更が、仕入控除税額へ与える影響を概算するブラウザツールです。

## 公開URL

- GitHub Pages: https://takatrp.github.io/invoice-transition-impact/
- Sites: https://invoice-transition-impact.takatrp0222.chatgpt.site/

## 主な機能

- UTF-8 / Shift_JISのCSVをブラウザ内だけで解析
- 単一列形式と借方・貸方形式の見出しを自動判定
- 読み取る課税区分・金額・税率・税額・仕入先・取引日列を画面で修正
- 80%・70%・50%・30%・0%の任意のBefore / After比較
- 元CSV全体の最古日から最新日までを対象期間として、影響額を365日換算
- 全額控除、個別対応方式、一括比例配分方式、簡易課税等の切替
- Before / After / 登録事業者100%の仕入控除税額と、仕入先別の差額を表示

## 計算対象

- 課税区分52：免税事業者等からの課税仕入れ（課税売上げ対応）
- 課税区分62：免税事業者等からの課税仕入れ（非課税売上げ対応）
- 課税区分72：免税事業者等からの課税仕入れ（共通対応）

経過措置率は令和8年度税制改正後の 80% → 70% → 50% → 30% → 0% を採用しています。

## 試算式

以下の試算式は、税込金額と消費税・地方消費税の合計ベースです。

```text
仕入税額相当額（標準税率） = 税込額 × 10 / 110
仕入税額相当額（軽減税率） = 税込額 × 8 / 108
制度変更の影響 = 配分後の仕入税額相当額 ×（Before率 - After率）
登録事業者との差 = 配分後の仕入税額相当額 ×（100% - After率）
年間換算の影響 = CSV期間の影響 × 365日 ÷ CSVの対象日数（最古日〜最新日、両端を含む）
```

実際の納付税額確定には、売上税額、端数処理、課税売上割合、保存要件、1仕入先ごとの上限、棚卸資産調整などの確認が必要です。
